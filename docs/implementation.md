# 正式版本实施记录

桌面可行性门已通过。依据用户批准的方案，继续实现本机 macOS 15+ 原生版本。

## 实施边界

- 分类展示不移动文件，隐藏桌面图标始终由用户在系统设置里完成。
- 首次授权桌面和项目总目录，真实目录由用户选择；不扫描全盘。
- 默认按类型投递，可切换至项目内指定目录；不覆盖、不合并、不跨卷移动。
- 每次投递先预检，保留操作日志；异常恢复和撤销均先核对身份及内容。
- 首次观察时间用于归档标记，不称为未打开时间；每周提醒可选，关闭应用时不保证提醒。
- 先测试临时文件，真实桌面移动需用户主动选择并确认。

## 实施顺序

1. 文件分类、快照、同卷独占移动、冲突预检、SwiftData 持久化。
2. 目录授权与观察、桌面分类窗口、预览、搜索及多选。
3. 归档选择、结果及历史撤销、提醒和布局恢复。
4. 自动化测试、隔离示例目录集成验证、发布构建和原生窗口截图检查。

本机版本使用 ad-hoc 签名，不等同于已签名公证的对外试用版本。

## 交付状态

上述四阶段的本机实现、自动化测试和隔离目录闭环验证已完成。
应用为 `dist/DesktopOrganizer.app`，使用及恢复说明见 `README.md`。
验证证据与未覆盖范围见 `release-validation.md`。
真实桌面首次授权和真实文件投递仍由用户主动完成。
