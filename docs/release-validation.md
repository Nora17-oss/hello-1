# 本机版本交付验证

后续更新：四看板版本 1.1.0（13）验证见 `four-boards-plan.md`，
包括 30 项测试、16 项集成检查及固定分类的跨进程持久化验证。
下方保留 1.0.0 的原始验证记录。

日期：2026-09-27。版本：1.0.0（12）。

## 环境与结果

- macOS 15.7.9，Intel；复用 Swift 6.2.3 Command Line Tools。
- 桌面验证版的 7 项人工场景由用户确认通过，详见 `verification-2026-09-27.md`。
- 27 项自动化测试通过，覆盖分类、计时、路径安全、冲突、归档、恢复及撤销等回归场景。
- 发布构建及本机 ad-hoc 签名验证通过，产物为 `dist/DesktopOrganizer.app`。
- 隔离示例的 12 项集成检查全部通过：索引、新增、改名、移除、首次观察时间、
  预检、移动、原路径消失、撤销、日志重新读取、第二轮移动及撤销。
  记录位于 `.build/qa-final/AppData/qa-result.json`。
- 独立三进程测试验证设置与日志实际落盘、重启后撤销、新增批次及再次加载。
  可使用 `scripts/test-persistence.sh` 重新执行。

## 视觉验证

- 已检查真实图片缩略图、中文长文件名换行及操作历史窗口。
- 在独立且未移动源图片的示例目录检查 Quick Look，图片内容实际显示，
  不仅检查窗口是否打开。截图为 `.build/preview-final/quicklook.png`。
- 示例目录与正式用户数据分离；示例中的手动操作不代表真实桌面归档验收。

## 安全与持久化

归档前分类只索引原路径。隔离测试验证移动后的目标内容及撤销恢复；
同名和变化检查用于拒绝覆盖，不自动删除存在歧义的副本。
日志在操作前保存，逐项记录结果；意外中断后核对源和目标。

本机 CLT 缺少 SwiftData 代码生成插件，使用公开 PersistentModel 接口。
已修正加载模型的 backing 初始化及属性修改通知问题；采用三个独立进程
验证落盘结果，避免把同一进程缓存误当成磁盘持久化。

## 尚未覆盖

- 用户真实桌面授权及真实项目投递需用户主动选择并确认，开发测试未代为执行。
- 实际每周系统通知送达、其他 Mac、Apple 芯片及其他系统版本尚未实机验证。
- 大规模文件压力测试和其他显示桌面手势未完成完整矩阵验证。
- 文件稳定性检查不锁住其他应用，不能保证检查后没有程序重新开始写入。
- 尚未进行 Developer ID 签名、公证及对外分发验证。

当前交付为本机可试用版本，不宣称所有发布环境已通过验收。
